# Question pipeline commands

- `npm run generate <week> [target]` — Groundwork candidate generation (local only, needs Claude API auth; writes `content/questions/week-NN.candidates.yaml`). Alternative, used for Weeks 1–2 of Fall 2026: generate in an interactive Claude Code session (subscription, no key) — reuse the SYSTEM prompt from `scripts/generate.js` (gen-v4 since 2026-09-20: parallel option lengths with the correct option mid-length, direct-question stems, name the source and spell out acronyms, real-claim distractors, no stem-to-key echo, bare-term option sets, feedback grounded like the stem, one item per keyed concept, proportional coverage, cross-source items only when the framework honestly applies), author the batch as structured JSON (`{type, stem, correct:{text,feedback}, distractors:[…×3], answerPos, selfExplainPrompt, sourceDoc, sourceLoc}`), then `npm run build-candidates <week> <file.json> [--model id]` writes the candidates file in the exact shape the API path produces and prints batch stats and lint warnings. Slide decks: `pdftotext` misses image-only slides — view those PDF pages directly before generating
- `npm run diff-decisions <a.json> <b.json> [--merge out.json]` — compare two curation reviews of one batch (the curator's export and an independent fresh-context review) and merge them for `curate`. Weeks 1–3 used both reviews; keep doing it
- `npm run review <week>` — builds `content/questions/week-NN.review.html` (gitignored) from the candidates file: a local keyboard-driven curation page (A/E/R, reject reason, free-text guidance note per question) with per-question lint warnings from `src/lib/candidates.js` (longest correct option, unexpanded acronyms, unnamed source, verbatim spans, which-reasoning stems). `npm run curate <week>` writes its exported decisions back into the candidates YAML (`pbpaste | npm run curate 1`); never edit candidate statuses by hand. `npm run promote <week> --ids a,b,c --title "…"` copies accepted/edited candidates into `week-NN.yaml` with sequential ids (`--force` to replace an existing file, `--publish` to go live) and stamps `promotedAs` on the candidates
- `npm run verify <file>` — bulk-check pasted completion logs (`--set N`, `--csv`, `--min-score 0.7` default; stdin if no file)

After each curation batch, add a row to `docs/EVAL-LOG.md` (root CLAUDE.md → Repository Conventions).
